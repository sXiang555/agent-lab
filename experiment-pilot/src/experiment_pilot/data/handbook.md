# 目标检测实验手册（演示数据）

## [protocol] 消融实验的可比性
比较 baseline 和改动时，保持数据划分、预训练权重来源、训练预算、优化器、
数据增强和评估口径一致。训练口径 ID 代表预先定义的控制条件，不包含被消融的
模型模块。不同数据划分上的 AP 差值不能归因到模块本身。

## [seeds] 随机种子与复现
单次同 seed 对照只能支持这组运行的观察。为估计波动，应在若干预先指定的 seed
上做成对对照，分别记录差值，并报告均值和离散程度。缺失 seed 要先补齐记录。

## [ap] AP 指标与评估口径
本项目的 AP 表示 COCO bbox AP@[.50:.95]，运行记录存为 0 到 1 的比例。
两次运行的绝对差值乘 100 后用 AP 点表达。AP50 和 AP_small 不能和主 AP 混用。
比较前核对评估器版本、评估集和推理设置。

## [small] 小目标 AP 诊断
当整体 AP 变化不大而 AP_small 变化明显时，可以进一步查看小目标召回、类别分布、
图像尺寸与定性样例。切分样本量小的时候，单次变化要结合成对复跑判断。

## [rerun] 补跑申请和人工审批
补跑需要提交待审批申请，列出候选运行、基线运行、数据划分、训练口径和 seed。
审批通过后写入持久化的演示队列，状态只代表已排队。驳回后不创建队列任务。

## [evidence] 证据缺失与复盘
如果日志、评估口径或 AP 缺失，记录缺项和来源。查不到对应运行时，请用户核对
运行编号。复盘引用运行记录和手册条目，定量结论应能从运行记录重新计算。

## [latency] 延迟与吞吐
延迟比较使用相同设备、输入大小、批大小和精度，记录是否含数据传输和后处理。
固定 warmup，再报告多次测量的中位数和 P95。GPU 同步影响单次计时的可解释性。

## [oom] 显存不足的定位
先检查失败发生在数据加载、前向、反向还是评估，记录输入分辨率、batch size、
精度与峰值显存。修改 batch size 后，用新的训练口径登记，原先 AP 对比需重新核对。
